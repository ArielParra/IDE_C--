# IDE C-- v1.3.0 — Semantic Analyzer

This release completes the semantic-analysis workspace: inspect the original syntax tree, compare its annotated copy, and explore the symbol table used by the analyzer.

## What's New

- **Annotated semantic tree:** declared and inferred types, safe constant-expression values, and visible `int`-to-`float` conversions. The original AST stays available in **Syntax**.
- **Live symbol table:** names, types, scopes, declaration positions, reference lines and logical storage offsets, including declarations from closed scopes.
- **Semantic checks:** undeclared identifiers, duplicate declarations, invalid assignments and operators, incompatible conversions, non-boolean conditions and use before initialization.
- **Current-buffer analysis:** **Semantic Analysis → Run Semantic Analysis** runs all three phases on the text currently in the editor, including unsaved changes. The Syntax Analysis action refreshes the same snapshot and selects the original AST. No saved token file is required.
- **Integrated diagnostics:** separate lexical, syntax and semantic errors with line/column navigation. Recoverable syntax errors retain a partial-results warning.
- **Navigation and copying:** expand the annotated tree, jump from nodes or symbol rows to source, and copy the tree or symbol table. Editing or opening another file clears old results.

## Downloads & Usage

All builds target **x86-64**.

### Windows

Download either ZIP, extract the complete folder, and run `IDE_C--.exe`:

- **`IDE_C--_windows_msys2.zip`** — recommended UCRT64 build.
- **`IDE_C--_windows_mingw.zip`** — alternative Fedora MinGW build.

Runtime DLLs are included; installing Rust or MSYS2 is unnecessary.

### Linux

- **`IDE_C--.AppImage`** — bundles GTK4 and application libraries. Run `chmod +x IDE_C--.AppImage`, then `./IDE_C--.AppImage`. If FUSE is unavailable, use `APPIMAGE_EXTRACT_AND_RUN=1 ./IDE_C--.AppImage`.
- **`IDE_C--`** — native binary built on Debian 13 (Trixie). Install GTK4 (4.10 or newer), GtkSourceView5 and the required runtime libraries on the host, then make the binary executable.

The Linux packages use the Debian Trixie glibc baseline. AppImage does not bundle glibc; older Linux distributions may require building from source. macOS binaries are not included.

## Verification

Download `SHA256SUMS` beside the four assets and run `sha256sum --check SHA256SUMS` on Linux. On Windows, use `Get-FileHash <archive> -Algorithm SHA256` and compare its digest with the corresponding entry.

The release workflow checks unit tests, GTK integration, Linux startup, Windows startup for both ZIPs, archive integrity, x86-64 architecture, runtime DLL dependencies and source-commit provenance before publication.

## Notes

Constant evaluation is limited to literal-only expressions; variable values and runtime behavior are not simulated. Symbol offsets are logical storage slots rather than physical memory addresses. The original `semantic.c--` demonstration includes intentional errors and produces partial analysis. Intermediate code generation is outside this release.
